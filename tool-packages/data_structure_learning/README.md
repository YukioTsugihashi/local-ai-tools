# データ構造学習 1.0.0

Excelの全行を読み、列数・列ごとの有効データ行数を集計します。
元の型、Excelの表示形式、空欄位置、重複関係を保つダミーデータを作成します。
計算・変換・出力はすべてPythonで行います。Ollamaや外部通信は不要です。
Open WebUIに独立した「データ構造学習」モデルとして登録する追加ツールです。

## インストール

1. `data_structure_learning-1.0.0.localtool` をUSB等で院内PCへコピーします。
2. 既存の `追加ツールの管理.cmd` をダブルクリックします。
3. 「ツールを追加...」を押し、上記ファイルを選びます。
4. 形式検査・単体テスト・合成サンプルの動作検査・登録が完了するまで待ちます。
5. Open WebUIを再読み込みし、モデル一覧の「【未承認】データ構造学習」を選びます。

既存の追加ツール受入基盤と `openpyxl==3.1.5` が必要です。
必要なライブラリは既存のrequirementsに含まれます。新たなインターネット接続は不要です。
承認は既存の院内管理手順で行います。承認状態はパッケージに埋め込みません。
院内Windows上での最終検査は、取り込み時に既存の管理アプリが実行します。

## 使い方

モデルを選び、Excelを1つ添付して次のように依頼します。

> このExcelのデータ構造を調べて、ダミーデータをExcelとCSVで作成して

入力は `.xlsx` / `.xlsm`。`.xls` はExcelで `.xlsx` に保存し直してください。
1行目はカラム名、2行目以降は全行を処理します。すべてのシートが対象です。
マクロ付き入力も読み取れますが、出力にマクロは含めません。

## 4つの出力

| ファイル | 内容 |
|---|---|
| `data_overview.xlsx` | シート概要・カラム概要・形式内訳・処理条件 |
| `dummy_data.xlsx` | 全シートのダミーデータ |
| `data_overview_csv.zip` | データ概要を1シート1CSVにしてまとめたもの |
| `dummy_data_csv.zip` | ダミーデータを1シート1CSVにしてまとめたもの |

CSVはUTF-8 BOM付きです。ZIP内の `sheet_index.csv` がCSV名と元シート名の対応です。
`sheet_001.csv` 以降が各シートです。Excel版とCSV版で同じダミー値を使います。
CSVは型・セル表示書式を保存できません。日付・時刻はISO表記、経過時間は日単位の数値で出力します。
CSVをExcelで直接開くと文字列の先頭0などが自動変換される場合があります。
型と書式を正確に保持した成果物にはExcel版を使ってください。

## 集計の定義

- 値のある最終行・最終列までを集計します。書式だけの末尾の行列は除外します。
- 範囲内の空行・空列・空欄位置は保持します。空のシートも保持します。
- 有効データは空欄・空文字以外です。数値0・False・空白文字は有効として数えます。
- カラム概要に列番号・カラム名・データ行数・有効行数・空欄数・型の件数を記録します。
- 形式内訳に列ごとの型とExcel表示形式と件数を記録します。元の具体的な値は載せません。

## 変換ルール

- カラム名・順序・シート名・行列数・空欄位置を保持します。
- 各セルの保存型と表示形式を保持します。日付らしい文字列を数値や日付型に変換しません。
- 通常の文字列は、文字列全体をキーとして仮名へ置換します。部分文字列の一致は保持しません。
- 原則は同じ文字数です。候補不足なら長くし、20文字を上限とします。
  元が20文字を超える通常文字列は20文字に短縮し、種類数を処理条件に記録します。
  上限内で一意に割り当てられなければ全体を中止し、部分成果物は返しません。
- 数字と区切り記号だけの文字列は数字部分を置換し、桁数・区切り記号・先頭の0を保持します。
  全桁が0の場合は最後の1桁も置換対象です。文字列の日付の暦上の妥当性は推測しません。
  例: 文字列の `20260816` は8桁の文字列のまま、数値の `20260816` は8桁の数値のままです。
- 数値は符号・整数部桁数・保存値の小数桁数と表示形式を保持します。
  Excelの数値精度に合わせ、有効桁の保持条件が15桁を超える値はエラーとします。
  大きな識別番号は元Excelで文字列として保存してください。
- Excelの日付・時刻・経過時間は対応する型の架空の値にします。対応する日付範囲は1900～9999年です。
- 文字・数値・日付・時刻・真偽値の同じ型の同じ値は、全シートで同じダミー値へ対応します。
  異なる元値は同じダミー値へ統合しません。型の異なる同じ見た目の値は別に扱います。
- 対応は1回の処理内で共通です。別の実行では新しい対応を作ります。対応表は保存・出力しません。
- 分布・大小関係・日付の前後関係・列間の計算上の整合性は保持対象ではありません。
- 数式は保存済みの計算結果をダミー化します。計算結果がなければ、Excelで再計算・保存するよう案内します。
  カラム名の数式、Excelエラー値は明示的に処理を止めます。
- 新規ブックにセル値と表示形式を作成します。原本を変更しません。
  元の数式・コメント・リンク・画像・マクロ・文書属性は引き継ぎません。
  元の色・罫線・列幅・結合セル等のレイアウトは複製しません。

## 開発・検証

リポジトリの `tool-packages/SPEC.md` に準拠しています。
変更は `tool-packages/data_structure_learning/` 内だけで完結します。

```bash
PYTHONPATH=tool-packages/data_structure_learning python -m pytest tool-packages/data_structure_learning/tests -q
python tools/toolpack_pack.py tool-packages/data_structure_learning
```

正式なpack処理が検査と `manifest.sha256` の生成を行います。
サンプルは `samples/make_sample.py` で生成する架空データです。
実データをテスト・サンプル・パッケージ・GitHubに含めません。
